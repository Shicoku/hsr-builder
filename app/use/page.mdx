# 使い方

## ビルドカードを作成する

1. トップページで、確認したいプレイヤーの9桁のUIDを入力します。
2. 矢印ボタンを押すと、公開されているキャラクター情報を取得します。
3. 表示された情報を確認し、ビルドカードを作成します。

UIDはゲーム内のプロフィール画面から確認できます。

## 注意事項

- プロフィールを公開しているプレイヤーのみ情報を取得できます。
- ゲーム側の更新やアクセス状況により、情報を取得できない場合があります。
- UIDは個人を特定する情報ではありませんが、他人のUIDを無断で利用しないでください。
